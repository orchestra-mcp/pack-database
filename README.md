# orchestra-mcp/pack-database

Database skills and agents for PostgreSQL, SQLite, and Redis

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-database
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-database")
```

## Contents

| Type | Names |
|------|-------|
| Skills | database-sync |
| Agents | dba, postgres-dba, sqlite-engineer, redis-engineer |
| Hooks | None |
